# MATH_NOTES — สมบัติของลอการิทึมที่ใช้ในโปรแกรม Log-Decoder

เอกสารนี้สรุปสมบัติ (properties) ของลอการิทึมทุกข้อที่ระบบ "ถอดรหัส" (rule engine ใน `src/engine/properties/`)
นำไปใช้จริงในการทำให้นิพจน์ง่ายและแก้สมการ เขียนในรูปแบบเดียวกับที่ปรากฏในหนังสือเรียนคณิตศาสตร์
ระดับมัธยมศึกษาตอนปลาย (สสวท.) เพื่อให้นักเรียนสามารถอ้างอิงและอธิบายให้ครูฟังได้ทุกขั้นตอน

**นิยาม:** กำหนดให้ `b > 0`, `b ≠ 1` และ `x > 0` เราเรียก `y = log_b(x)` ว่า ลอการิทึมฐาน b ของ x
ก็ต่อเมื่อ `b^y = x` กล่าวคือ ลอการิทึมคือ "เลขชี้กำลังที่ต้องยกฐาน b เพื่อให้ได้ x" เงื่อนไข `b > 0, b ≠ 1, x > 0`
เรียกว่า **โดเมนของลอการิทึม** และเป็นสิ่งที่โปรแกรมตรวจสอบก่อนทุกครั้งที่คำนวณ (ไฟล์ `src/engine/domain.ts`,
`domain-collect.ts`)

---

## 1) สมบัติผลคูณ (Product Rule) — `src/engine/properties/productRule.ts`

**สมบัติ:** ถ้า `b > 0, b ≠ 1, x > 0, y > 0` แล้ว

```
log_b(xy) = log_b(x) + log_b(y)
```

**ตัวอย่าง:** `log_2(4·8) = log_2(4) + log_2(8) = 2 + 3 = 5` ตรวจสอบ: `log_2(32) = 5` ✓

---

## 2) สมบัติผลหาร (Quotient Rule) — `src/engine/properties/quotientRule.ts`

**สมบัติ:** ถ้า `b > 0, b ≠ 1, x > 0, y > 0` แล้ว

```
log_b(x/y) = log_b(x) - log_b(y)
```

**ตัวอย่าง:** `log_3(81/9) = log_3(81) - log_3(9) = 4 - 2 = 2` ตรวจสอบ: `log_3(9) = 2` ✓

---

## 3) สมบัติเลขยกกำลัง (Power Rule) — `src/engine/properties/powerRule.ts`

**สมบัติ:** ถ้า `b > 0, b ≠ 1, x > 0` และ `k` เป็นจำนวนจริงใดๆ แล้ว

```
log_b(x^k) = k·log_b(x)
```

**ตัวอย่าง:** `log_2(8^2) = 2·log_2(8) = 2·3 = 6` ตรวจสอบ: `log_2(64) = 6` ✓

---

## 4) การเปลี่ยนฐาน (Change of Base) — `src/engine/properties/changeOfBase.ts`

**สมบัติ:** ถ้า `a, b > 0, a ≠ 1, b ≠ 1, x > 0` แล้ว

```
log_b(x) = log_a(x) / log_a(b)
```

โดยทั่วไปเลือก `a = 10` หรือ `a = e` เพื่อคำนวณด้วยเครื่องคิดเลข

**ตัวอย่าง:** `log_2(50) = ln(50)/ln(2) ≈ 3.912023/0.693147 ≈ 5.6439`
โปรแกรมใช้สมบัตินี้ตรวจสอบความสอดคล้อง (consistency) — คำนวณด้วยฐานธรรมชาติแล้วต้องได้ค่าเดียวกันเสมอ
(ดูเทสต์ `log_2(50) equals ln(50)/ln(2)` ใน `src/engine/__tests__/evaluate.test.ts`)

---

## 5) เอกลักษณ์ log ของฐานตัวเอง (`log_b(b) = 1`) — `src/engine/properties/logBaseSelf.ts`

**สมบัติ:** ถ้า `b > 0, b ≠ 1` แล้ว

```
log_b(b) = 1
```

**เหตุผล:** จากนิยาม ต้องหาเลขชี้กำลัง `y` ที่ `b^y = b` ซึ่งคือ `y = 1` เสมอ

**ตัวอย่าง:** `log_5(5) = 1`, `log_0.5(0.5) = 1`

---

## 6) เอกลักษณ์ log ของ 1 (`log_b(1) = 0`) — `src/engine/properties/logOfOne.ts`

**สมบัติ:** ถ้า `b > 0, b ≠ 1` แล้ว

```
log_b(1) = 0
```

**เหตุผล:** จากนิยาม ต้องหาเลขชี้กำลัง `y` ที่ `b^y = 1` ซึ่งคือ `y = 0` เสมอ (เพราะ `b^0 = 1` ทุก `b ≠ 0`)

**ตัวอย่าง:** `log_2(1) = 0`, `log_10(1) = 0`, `ln(1) = 0`

---

## 7) เอกลักษณ์ผกผัน (Inverse Identities)

### 7.1 `b^(log_b x) = x` — `src/engine/properties/inverseLogExp.ts`

**สมบัติ:** ถ้า `b > 0, b ≠ 1, x > 0` แล้ว

```
b^(log_b x) = x
```

**เหตุผล:** ฟังก์ชันเลขชี้กำลัง `b^t` และฟังก์ชันลอการิทึม `log_b(t)` เป็นฟังก์ชันผกผันซึ่งกันและกัน
การยกกำลัง `b` ด้วยค่า `log_b x` จึง "ย้อนกลับ" ให้ได้ `x` เดิม

**ตัวอย่าง:** `2^(log_2 8) = 2^3 = 8`

### 7.2 `log_b(b^k) = k` — `src/engine/properties/inverseExpLog.ts`

**สมบัติ:** ถ้า `b > 0, b ≠ 1` และ `k` เป็นจำนวนจริงใดๆ แล้ว

```
log_b(b^k) = k
```

**ตัวอย่าง:** `log_3(3^5) = 5`, `log_10(10^-2) = -2`

---

## 8) ลอการิทึมธรรมชาติ (`ln = log ฐาน e`) — `src/engine/properties/lnIsLogBaseE.ts`

**นิยาม:** `ln(x) = log_e(x)` โดย `e ≈ 2.718281828...` เป็นค่าคงตัวออยเลอร์ (Euler's number)
ลอการิทึมธรรมชาติเป็นกรณีพิเศษของลอการิทึมทั่วไปเมื่อฐาน `b = e` จึงมีสมบัติทุกข้อข้างต้นเหมือนกันทุกประการ
โปรแกรมแปลง `ln(x)` เป็น `log_e(x)` ภายในก่อนประมวลผล เพื่อให้ใช้ rule engine ชุดเดียวกันได้

**ตัวอย่าง:** `ln(1) = 0`, `ln(e) = 1`, `e^(ln 5) = 5`

---

## 9) การจัดรูปพีชคณิตพื้นฐาน — `src/engine/properties/simplifyArithmetic.ts`, `equals.ts`

ใช้จัดรูปนิพจน์ตัวเลขที่ไม่มีลอการิทึม (เช่น การบวก ลบ คูณ หาร เศษส่วน) ด้วยเลขคณิตตรรกยะ (exact rational
arithmetic บน `bigint`, ดู `src/engine/rational.ts`) เพื่อให้ผลลัพธ์แม่นตรง 100% เมื่อคำตอบเป็นจำนวนตรรกยะ
เช่น `log_2(8) = 3` พอดี ไม่ปัดเศษเป็น `2.9999999999999996` แบบ floating point ทั่วไป

---

## เงื่อนไขข้อผิดพลาด (สิ่งที่ log ไม่นิยาม)

จากนิยาม `y = log_b(x) ⇔ b^y = x` โดยมีเงื่อนไข `b > 0, b ≠ 1, x > 0` จึงสรุปได้ว่า **ไม่นิยาม** เมื่อ

| กรณี | เหตุผลทางคณิตศาสตร์ |
|---|---|
| `b ≤ 0` | ฟังก์ชันเลขชี้กำลัง `b^y` ไม่ต่อเนื่อง/ไม่นิยามสำหรับเลขชี้กำลังที่ไม่ใช่จำนวนเต็มเมื่อฐานติดลบ |
| `b = 1` | `1^y = 1` เสมอทุกค่า `y` จึงหา `y` ที่ทำให้ `1^y = x` ไม่ได้อย่างเดียว (ไม่ใช่ฟังก์ชัน 1-1) |
| `x ≤ 0` | ไม่มีจำนวนจริง `y` ใดที่ทำให้ `b^y ≤ 0` เมื่อ `b > 0` (เลขชี้กำลังของฐานบวกให้ผลบวกเสมอ) |

โปรแกรมตรวจสอบเงื่อนไขเหล่านี้ก่อนคำนวณทุกครั้ง (`src/engine/domain.ts`) และแสดงข้อความอธิบายเป็นภาษาไทย
พร้อมปฏิเสธการคำนวณอย่างปลอดภัย ไม่มีทาง throw error หรือได้ `NaN` เงียบๆ

---

## การประยุกต์: ตรวจคำตอบแปลกปลอม (Extraneous Root)

เมื่อแก้สมการลอการิทึม เช่น `log_2(x) + log_2(x-2) = 3` ขั้นตอนคือ

1. ใช้ **สมบัติผลคูณ** รวม: `log_2(x(x-2)) = 3`
2. ใช้ **นิยามลอการิทึม** (ยกกำลัง 2 ทั้งสองข้าง): `x(x-2) = 2^3 = 8`
3. จัดรูปเป็นสมการกำลังสอง: `x² - 2x - 8 = 0 → (x-4)(x+2) = 0 → x = 4` หรือ `x = -2`
4. **ตรวจโดเมนย้อนกลับ**: `x = 4` ให้ `log_2(4) + log_2(2)` นิยามได้ (ผ่าน ✓) แต่ `x = -2` ให้ `log_2(-2)`
   ซึ่ง **ไม่นิยาม** เพราะอาร์กิวเมนต์ติดลบ จึงต้องตัดทิ้ง (คำตอบแปลกปลอม ✗)

ขั้นตอนการยกกำลังทั้งสองข้าง (ขั้นที่ 2) เป็นการดำเนินการที่ไม่ผันกลับได้เสมอ (not always reversible) เพราะ
โดเมนของ `log_2(x(x-2))` แคบกว่าโดเมนของ `x(x-2)` เอง จึงอาจทำให้ได้คำตอบเกินมาที่ต้องตรวจสอบและตัดทิ้ง
