# Log-Decoder

**Log-Decoder** เป็นเว็บแอปพลิเคชันสำหรับโครงงานคณิตศาสตร์ระดับมัธยมศึกษา ช่วย "ถอดรหัส" นิพจน์และสมการลอการิทึม
ทีละขั้นตอน พร้อมอธิบายว่าแต่ละขั้นใช้สมบัติ (property) ใดของลอการิทึม และเชื่อมโยงลอการิทึมเข้ากับปรากฏการณ์
ในโลกจริง (แผ่นดินไหว, เสียง, ค่า pH) ทุกส่วนของแอปเป็นภาษาไทยทั้งหมด

## แอปนี้ทำอะไรได้บ้าง

### 1. ตัวช่วยแก้ลอการิทึม (Log Property Simplifier & Solver)
ป้อนนิพจน์หรือสมการลอการิทึมแบบข้อความอิสระ เช่น

- `log_2(8)`, `log2(8)`, `log_2 8`, `log(1000)`, `ln(1)`
- `log_2(x) + log_2(x-2) = 3` (สมการลอการิทึม)
- `2^x=50`, `3^(x+1)=81`, `5^(2x)=7^x` (สมการเลขชี้กำลัง)

แล้วระบบจะ:
1. แสดง **แผงเงื่อนไข/โดเมน** ก่อนเริ่มแก้ (อาร์กิวเมนต์ > 0, ฐาน > 0 และ ≠ 1)
2. แสดง **ขั้นตอนการแก้ทีละขั้น** พร้อมชื่อสมบัติที่ใช้ (เช่น สมบัติผลคูณ, สมบัติผลหาร, สมบัติเลขยกกำลัง) และ
   tooltip "ทำไมถึงทำแบบนี้" อธิบายเป็นภาษาไทยล้วนๆ ๑ ประโยค
3. แสดง **คำตอบแบบแม่นตรง (exact)** ก่อน แล้วตามด้วยค่าประมาณทศนิยม
4. **ตรวจคำตอบแปลกปลอม (extraneous root)** โดยแทนค่าคำตอบทุกตัวกลับเข้าไปในเงื่อนไขโดเมน แล้วบอกเหตุผลชัดเจนว่า
   เพราะเหตุใดคำตอบตัวใดถูกตัดทิ้ง

### 2. เครื่องคิดเลขมาตราส่วนโลกจริง (Real-World Scale Calculator)
สามแท็บ คำนวณได้ทั้งสองทิศทาง พร้อมแสดงสูตรที่แทนค่าแล้วและวิธีทำ:

- **ริกเตอร์ (แผ่นดินไหว)**: M = log₁₀(A/A₀), log₁₀E = 4.8 + 1.5M — และโหมดเปรียบเทียบพลังงาน
- **เดซิเบล (เสียง)**: β = 10·log₁₀(I/I₀), I₀ = 10⁻¹² W/m² — และโหมดเปรียบเทียบความเข้มเสียง
- **pH (กรด-เบส)**: pH = -log₁₀[H⁺], pH + pOH = 14 — และโหมดเปรียบเทียบความเป็นกรด

แต่ละแท็บมีแถบเทียบระดับ (scale strip) อ้างอิงค่าจริง และตรวจสอบค่าที่เป็นไปไม่ได้ในทางฟิสิกส์ (เช่น ความเข้มติดลบ)

### 3. ฟีเจอร์สร้างสรรค์
- กราฟเชิงโต้ตอบ y = log_b(x) พร้อมสไลเดอร์ปรับฐาน b, เส้นกำกับแนวตั้งที่ x=0, จุดคงที่ (1,0) และจุดคำตอบ
- "Decoder" reveal animation: ขั้นตอนการแก้ปรากฏทีละขั้นด้วยปุ่ม "ขั้นถัดไป"
- โหมดฝึกฝน: สุ่มโจทย์ตามระดับความยาก ตรวจคำตอบ และดูเฉลยทีละขั้นตอนได้
- ปุ่มคัดลอกคำตอบ/ขั้นตอนทั้งหมดเป็น LaTeX หรือข้อความธรรมดา
- ธีม "decoder terminal" มืด สำเนียง monospace เป็นธีมหลักของแอป

## คณิตศาสตร์เบื้องหลัง (สรุป)

ดูรายละเอียดทุกสมบัติที่ implement พร้อมสูตรแบบตำราเรียนไทยได้ที่ [`MATH_NOTES.md`](./MATH_NOTES.md)
และดู flow การประมวลผลได้ที่ [`FLOWCHART.md`](./FLOWCHART.md)

หลักการสำคัญ:
- คำนวณด้วยเลขคณิตตรรกยะ (exact rational, bigint) ก่อนเสมอ เพื่อให้ `log_2(8)` ได้ `3` พอดี ไม่ใช่ `2.9999999999999996`
- ถ้าไม่สามารถหาค่า exact ได้ (เช่น log_2(50)) จะคำนวณด้วย `decimal.js` ที่ความละเอียด 50 หลัก แล้วแสดงเป็นค่าประมาณ

## เทคโนโลยีที่ใช้

| ส่วนประกอบ | เทคโนโลยี |
|---|---|
| Framework | React 19 + TypeScript + Vite |
| สไตล์ | Tailwind CSS v4 |
| Parser/Tokenizer นิพจน์ | mathjs (ใช้เฉพาะ parse/tokenize — ไม่ใช้ `simplify()`) |
| เลขคณิตแม่นยำสูง | decimal.js + เลขคณิตตรรกยะบน `bigint` (เขียนเอง) |
| แสดงสูตรคณิตศาสตร์ | KaTeX |
| ทดสอบ | Vitest |
| ฟอนต์ | Sarabun / IBM Plex Sans Thai (Google Fonts) |

**ระบบกฎ (rule engine)** สำหรับสมบัติลอการิทึมเขียนขึ้นเองทั้งหมดบน AST (`src/engine/ast.ts`) — ไม่ได้พึ่งพา
`mathjs.simplify()` — เพื่อให้ทุกขั้นตอนระบุชื่อสมบัติที่ใช้ได้อย่างถูกต้องตามหลักการสอน

## โครงสร้างโปรเจกต์ (ส่วนสำคัญ)

```
src/
  engine/            แกนคำนวณ: AST, parser, evaluator, rule engine, ตัวแก้สมการ
    properties/       กฎแต่ละสมบัติ แยกไฟล์ละหนึ่งสมบัติ
    __tests__/         เทสต์ของ engine
  scales/            สูตรมาตราส่วนโลกจริง (ริกเตอร์/เดซิเบล/pH)
  data/              ข้อมูลอ้างอิง (scale strip)
  components/        UI components (React)
  strings.ts         ข้อความภาษาไทยทั้งหมดของแอป (จุดเดียว)
```

## วิธีรันโปรเจกต์ในเครื่อง

ต้องมี Node.js เวอร์ชัน 20 ขึ้นไป

```bash
npm install        # หรือ pnpm install
npm run dev         # เปิดเซิร์ฟเวอร์พัฒนา (http://localhost:5173)
npx vitest run       # รันชุดทดสอบทั้งหมด
npm run build        # สร้างไฟล์ static สำหรับ deploy (ออกที่ dist/)
npm run preview      # ดูตัวอย่างไฟล์ build ก่อน deploy จริง
```

## วิธี Deploy (ฟรี, ไม่มี backend)

โปรเจกต์นี้เป็น static site ล้วนๆ (ไม่มี backend/database) จึง deploy ได้ฟรีบนแพลตฟอร์มใดก็ได้ต่อไปนี้:

### Vercel
```bash
npm install -g vercel
vercel --prod
```
หรือเชื่อมต่อ repo กับ Vercel ผ่านหน้าเว็บ แล้วตั้งค่า Build Command เป็น `npm run build` และ Output
Directory เป็น `dist`

### Netlify
```bash
npm install -g netlify-cli
netlify deploy --prod --dir=dist
```
หรือเชื่อมต่อ repo ผ่านหน้าเว็บ Netlify แล้วตั้งค่า Build Command เป็น `npm run build` และ Publish
Directory เป็น `dist`

### GitHub Pages
```bash
npm run build
npx gh-pages -d dist
```
(ต้องตั้งค่า `base` ใน `vite.config.ts` ให้ตรงกับชื่อ repository เช่น `base: '/log59819/'` ถ้า deploy ไปที่
`https://<user>.github.io/log59819/`)

## ข้อจำกัดที่ทราบ

- ตัวแก้สมการรองรับสมการลอการิทึมที่ทุกพจน์ log มีฐานเดียวกัน และพจน์ที่ไม่ใช่ log ต้องไม่มีตัวแปรปน (ตรงตามระดับ
  มัธยมศึกษา) และรองรับพหุนามที่ได้จากการรวม log สูงสุดดีกรี 2 (สมการกำลังสอง)
- สมการเลขชี้กำลังรองรับกรณีที่เลขชี้กำลังเป็นนิพจน์เชิงเส้นของ x (เช่น `x`, `2x`, `x+1`) ซึ่งครอบคลุมโจทย์ระดับ
  มัธยมศึกษาทั้งหมด
